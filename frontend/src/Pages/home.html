From raw telemetry to your pocket

A four-stage pipeline turns NASA/ESA data feeds into plain-language insights.

01
Ingest
Raw telemetry arrives from NASA, ESA, and Launch Library APIs. Deterministic fields — coordinates, timestamps — are persisted immediately, untouched.
02
Agent A — Enrichment
The Astro-Contextualizer worker dispatches to Claude. It writes the description and viewing advice. A Zod schema blocks any attempt to alter times or geometry.
03
Geo-match
PostGIS ST_Contains checks each user's home point against the event's visibility polygon. Matched users get Notification rows created — idempotently.
04
Agent B — Dispatch
At T-24h, the Observation Concierge pulls live weather and light-pollution data for your exact location, then writes a hyper-personal push notification.
